# Door Commander Web Installer

Tento projekt umožňuje inštaláciu firmware do ESP32 zariadenia cez prehliadač pomocou [ESP Web Tools](https://esphome.github.io/esp-web-tools/).

## Použitie
1. Pripojte ESP32 k počítaču cez USB
2. Otvorte stránku GitHub Pages tohto projektu
3. Kliknite na **Install**
4. Vyberte port a spustite nahrávanie firmware
